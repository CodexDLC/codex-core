# Необязательный навык для агентов

Начиная с версии `codex-core` 0.5.0 пакет Python содержит автономный навык использования библиотеки для кодовых агентов. Установите пакет в среду Python, из которой будете запускать команды, затем выполните их из корня проекта-потребителя:

```bash
python -m pip install "codex-core>=0.5.0"
python -m codex_core.agent_skills install --project .
python -m codex_core.agent_skills status --project .
```

Установщик создаёт `.agents/skills/codex-core/` с манифестом версии и хешей и добавляет помеченную инструкцию в `AGENTS.md`. Копией навыка и манифестом управляет пакет. Правила вашего приложения храните в собственном навыке проекта или вне помеченного блока.

Обновление пакета Python и обновление установленного навыка — отдельные действия:

```bash
python -m pip install --upgrade codex-core
python -m codex_core.agent_skills update --project .
python -m codex_core.agent_skills status --project .
```

Чтобы удалить только файлы установщика, выполните `python -m codex_core.agent_skills delete --project .`. Повторный `install` допустим, если навык актуален; `delete` также успешно завершается, если навык уже отсутствует. `status` возвращает код 0 только для установленного и актуального навыка; если навык отсутствует, устарел или повреждён, возвращается код 1. Остальные команды возвращают код 1 при ошибке.

Команды `update` и `delete` откажутся удалять изменённые управляемые файлы. Установка также откажется занимать существующий неуправляемый каталог или перезаписывать конфликтующий файл. Если команда обнаружила локальные изменения, сохраните их в собственном навыке проекта, восстановите управляемые файлы или помеченный блок из надёжной резервной копии установленной версии и повторите команду. Не меняйте манифест ради принятия изменений и не удаляйте каталог вручную для принудительного обновления. Остальной текст `AGENTS.md` и неуправляемые файлы сохраняются.
